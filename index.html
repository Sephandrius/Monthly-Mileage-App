MILEAGE REIMBURSEMENT PROCESSOR

HOW TO USE THIS TOOL ▼

WHAT IS THIS TOOL FOR?

This tool processes employee mileage spreadsheets for reimbursement. Upload Excel files containing mileage data, and the tool will validate mileage totals, apply the correct IRS reimbursement rate, and generate a summary report for payroll processing.

STEP-BY-STEP INSTRUCTIONS

  1. Select your files: You have three options:
    • Drag and drop: Simply drag Excel files or folders containing Excel files directly into the drop area.
    • Select individual files: Click the "SELECT FILES" button and choose one or more Excel files.
    • Select an entire folder: Click the "SELECT FOLDER" button and choose a folder containing Excel files.
  2. Review your selection: You'll see a list of the files you've selected.
  3. Process files: Click the "PROCESS FILES" button. The app will analyze the data.
  4. Wait for processing: A progress indicator will show while your files are being processed.
  5. Review results: Review the summary table that appears with your results.
  6. Export results: Click the "EXPORT TO EXCEL" button to download a formatted summary spreadsheet for payroll.

TIPS FOR SUCCESS

Note: If you're working with a large number of files, the processing might take a few minutes. Please be patient and don't close the browser window during processing.

Each spreadsheet should have employee name in cell D2, total miles in D3, IRS rate in D4, reimbursement amount in D5, and trip entries starting from row 7.

TROUBLESHOOTING

  1. No files appear after selection: Make sure you're selecting Excel files (.xlsx or .xls).
  2. The "PROCESS FILES" button is grayed out: You need to select at least one Excel file before processing.
  3. Invalid data warnings: If you see discrepancy warnings, check that the reported totals match the sum of individual trips.
  4. Still have issues? Contact Joseph Winters for any further support.

NO SURPRISES

This tool operates entirely within your browser. No files are uploaded to external servers, making it safe for confidential company documents. Your data never leaves your device.
